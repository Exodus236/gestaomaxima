# Run and deploy your AI Studio app

This contains everything you need to run your app locally.

View your app in AI Studio: https://ai.studio/apps/b7db112f-c746-4784-a270-44da7ec14c98

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Run the app:
   `npm run dev`

## Histórico e pós-venda

- Para um banco Supabase existente, execute `supabase_features_migration.sql` no SQL Editor. Essa migração adiciona as colunas de serviços, histórico e pós-venda sem limpar dados.
